GastosVercel is an Express-on-Vercel app written in **plain JavaScript** (originally copied from vercel/examples solutions/express in TypeScript, later converted to JS). Entry point `src/index.js` exports the app; static assets in `public/` are served by the Vercel CDN (NOT `express.static`). Connected to GitHub repo `Arkhand/Gastos` (branch `main`) → Vercel auto-deploys on every push.

- Vercel project: **gastos**, team/org **arkhand** (linked via `.vercel/project.json`).
- Live production URL: **https://gastos-danis.vercel.app** (other aliases 401 via Deployment Protection; `gastos-mocha-one` is stale).

**Structure (layered MVC, like the dev.to folder-structure article the user follows):** `src/config/` (env.js centralizes ALL process.env reads; passport.js), `src/controllers/`, `src/middlewares/` (auth.js = `requireAuth`, errorHandler.js), `src/models/` (db.js = Supabase, see [[supabase]]; ia.js = Gemini), `src/config/categorias.js` (8 categorías fijas: comida, super, transporte, salidas, salud, hogar, servicios, otros), `src/utils/fecha.js` (hoy/ayer en horario AR), `src/routes/` (thin), `src/views/*.ejs` (+ partials: header, footer, tabbar, chubi, sheet), `public/app.js` (voz Web Speech + hoja inferior).

**The app is a voice-first redesign** (June 2026, reproduciendo el proyecto claude.ai/design "Gastos" del usuario — look "chibi", fuentes Fredoka+Nunito, paleta coral, mascota CSS "Chubi"). Pantallas (tab bar Cargar/Resumen/Nosotros): `/` = landing (redirige a `/inicio` si está logueado), `/inicio` = home (mascota + micrófono de voz + últimos gastos agrupados por día + FAB + hoja inferior para cargar/editar), `/resumen` = totales por categoría del mes, `/nosotros` = familia con fotos circulares con aro (`public/mama.jpg`/`papa.jpg`/`nena.jpg`: avatares 3D del diseño, optimizados a 440px JPEG con sharp; los chibis CSS de `chibi.jsx` quedaron SIN uso en `style.css`). Nota: las `assets/*.png` del diseño pesan >256KB y NO se pueden bajar por DesignSync `get_file` (cap 256KB → truncado); las aportó el usuario a mano en `public/`. Cargar/editar/borrar van por la hoja: `POST /nuevo`, `POST /gastos/:id/editar`, `POST /gastos/:id/eliminar`. Voz: `POST /api/interpretar`. GET `/nuevo`,`/gastos`,`/gastos/:id/editar` redirigen a `/inicio` (compat). All app routes `requireAuth`; públicas solo `/` y `/healthz`. `callbackGoogleOk` redirige a `/inicio` (antes `/perfil`, que ya no existe). **Libro compartido:** `db.js` ya NO filtra por `user_id` — `listarGastos`/resumen/`actualizarGasto`/`eliminarGasto` operan sobre TODOS los gastos de la familia (las firmas mantienen un primer arg `_userId` que se ignora). Cada gasto guarda `cargado_por` (displayName de quien lo cargó) y `a_nombre_de` = la **persona** que hizo el gasto, almacenada como EMAIL (`musiald@gmail.com`=Dani Hombre, `danielapaulacastelli@gmail.com`=Dani Mujer; `config/personas.js`: id=email, `label`, `normalizarPersona`, `personaLabel`, `personaPorDefecto(email)`). Se elige en el segmented de la hoja, la IA la mapea desde la voz, y se muestra el `label` en gris bajo la descripción. **Borrado lógico**: la tabla `gastos` tiene `eliminado boolean default false`; nada se borra físico — `eliminarGasto` marca `eliminado=true` y `actualizarGasto` da de baja el registro viejo + inserta uno nuevo (historial). `listarGastos` filtra `eliminado=false`. **Edición**: se hace en `/resumen` (lista editable que abre la hoja con un botón ✏️ por fila — la fila no es clickeable; botón "Guardar edición"); `/inicio` es solo lectura. Borrar pide confirmación. Fila de gasto unificada en `partials/gasto-row.ejs` (misma en inicio y resumen). **Montos en ambas monedas**: cada gasto guarda `monto`+`moneda` y además `monto_ars`+`monto_usd` (columnas numeric); la conversión usa el dólar bolsa de dolarapi.com (`/v1/dolares/bolsa`, promedio compra/venta) vía `src/models/cotizacion.js` (cacheado 30 min en memoria). **Resumen** tiene un segmented "Gastos | Gráficos"; Gráficos = torta (CSS `conic-gradient`) + barras por categoría (sobre `monto` ARS del mes) + card "Total por persona" con total ARS y USD (suma `monto_ars`/`monto_usd` del mes).

**Vercel gotchas (do NOT remove these):**
- `vercel.json` `{ "framework": "express" }` — the project was created from an EMPTY repo, so the Framework Preset locked to "Other" and every route 404'd; this overrides it.
- `vercel.json` `functions["src/index.js"].includeFiles: "src/views/**"` — EJS templates are read at runtime by path, which Vercel's bundler (nft) does NOT trace, so without this the views are missing from the function and `res.render` 500s. Also set `app.set('views', path.join(process.cwd(),'src','views'))` (process.cwd, not __dirname, is the reliable base in the function).
- Passport 0.6+ calls `req.session.regenerate/save` which cookie-session lacks → a no-op shim in `src/index.js`.

**Google login is LIVE** (Passport `passport-google-oauth20` + stateless `cookie-session`). Config in `src/config/passport.js`; `requireAuth` in `src/middlewares/auth.js`. Env vars `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `SESSION_SECRET` set in Vercel (Production + Development; Preview skipped). Registered redirect URI: `https://gastos-danis.vercel.app/auth/google/callback`. OAuth consent screen in Testing mode → only added test users (e.g. musiald@gmail.com) can log in. User profile is stored in the signed session cookie (no users table). **Acceso restringido a la familia (lista blanca):** `src/config/acceso.js` define los emails permitidos (`musiald@gmail.com`, `danielapaulacastelli@gmail.com`; override por env `ALLOWED_EMAILS` separada por comas, leída en `config.allowedEmails`). Se valida en 2 capas: `passport.js` rechaza el login (`done(null,false)`) si el email no está, y `requireAuth` lo revalida en cada request (si no, `req.logout` + redirect `/?error=acceso`; API→403). La landing muestra el aviso con `?error=acceso`/`auth`. OJO: como el consent screen sigue en **Testing**, cada email permitido ADEMÁS debe estar como *test user* en Google Cloud o Google lo frena antes de llegar a la app. (Al 2026-06-15 ya están agregados como test users tanto `musiald@gmail.com` como `danielapaulacastelli@gmail.com`, así que ambos pueden loguearse.)

**Voz con IA (Gemini):** el navegador transcribe con la Web Speech API (`es-AR`, en `public/app.js`) y postea el texto a `POST /api/interpretar`; el servidor (`src/models/ia.js` + `src/controllers/iaController.js`) llama a Google Gemini (modelo `gemini-2.5-flash` por defecto, salida JSON estructurada) y devuelve `{descripcion, monto, moneda, categoria, fecha}` que precarga la hoja para confirmar. **Env var `GEMINI_API_KEY`** (solo servidor, en `config.gemini`) — ya cargada en Vercel Production vía CLI (`vercel env add`, 2026-06-14; la CLI ya tenía sesión `musiald-9145`). La key AUTENTICA OK y el modelo `gemini-2.0-flash` existe, PERO el proyecto de esa key tiene **cuota 0 en free tier → HTTP 429** (`free_tier_requests, limit: 0`). Hasta habilitar billing/quota en Google AI Studio (o usar una key de un proyecto con free tier), la IA no responde y la voz cae a **modo manual** (app.js rellena la descripción con lo transcripto). Cambiar la key: `vercel env rm GEMINI_API_KEY production` + `vercel env add` + redeploy. Web Speech anda en Chrome/Android (el objetivo), flojo en iOS. La key se rota después.

**PWA (installable, static-only cache):** `public/manifest.webmanifest` (display standalone, theme #f2895f coral, bg #fbf3ea) + `public/sw.js` (caches ONLY static assets — css/png/manifest; pages and data always go to network, so no cross-user/stale data). Icons `icon-192/512/512-maskable.png` generated from `logo.png` (1000x1000) with sharp (sharp then uninstalled — it was a one-off tool). SW registered in `views/partials/footer.ejs`; manifest/theme/apple-touch-icon linked in `views/partials/header.ejs`. Main goal was Android installability.
